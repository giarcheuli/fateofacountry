# ბედი ქართლისა · Fate of Georgia

A bilingual, read-only public information portal focused on Georgia. It organizes 18 public-interest topics and links to selected public sources. Georgian is the default language; visitors can switch to English.

## Run locally

Open `index.html` in a modern browser. No build step or external runtime dependencies are required.

This prototype currently provides topic descriptions and source links, not live news or independently verified analysis. Sources are general starting points; consult the original publication for the relevant information, dates, and methodology. Some topic sources are still being prepared.

There are no accounts, private workspaces, or user content-entry features.
