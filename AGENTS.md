# Instructions for coding assistants

Before making changes, read `README.md` and the relevant files under `docs/`. Follow [the product and software documentation convention](docs/product-documentation.md).

Keep implementation-facing product and technical decisions in this repository as well as the matching Google Drive project knowledge. Update the relevant docs with material decisions and artifact changes; distinguish proposals from approved decisions and implemented behavior. Do not treat a plan as completed implementation. Run only the checks requested for the task or documented as required, and report actual results and remaining blockers.
